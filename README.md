# Number-Based Programs Using While Loops (C++)

A collection of beginner-friendly C++ programs that solve different number-related problems using `while` loops.

# Programs Included

| No. | Program | Description |
|---|---|---|
| 1 | Armstrong Number | Checks whether a number is an Armstrong number. |
| 2 | Fibonacci Series | Generates the Fibonacci series up to a given limit. |
| 3 | Harshad Number in Range | Finds Harshad numbers within a given range. |
| 4 | Number of Digits | Counts the total number of digits in a number. |
| 5 | Perfect Number | Checks whether a number is a perfect number. |
| 6 | Prime Number in Range | Displays all prime numbers within a given range. |
| 7 | Prime Number | Checks whether a number is prime. |
| 8 | Reverse Number | Reverses the digits of a given number. |
| 9 | Strong Number | Checks whether a number is a Strong number. |
| 10 | Sum of Even and Odd Digits | Calculates the sum of even and odd digits separately. |
